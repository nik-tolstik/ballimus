## Guidance for contributors and coding agents

- Use this project as the canonical place for planning and tracking Football Bot work.
- Associate work with an issue in the `FBOT` team and the Football Bot project when the work is tracked in Linear.
- Before starting implementation, move the associated issue to `In Progress`.
- Keep the issue in `In Progress` while its pull request is open, under review, or waiting for follow-up work.
- Move the issue to `Done` only after its implementation has been merged into `main`.
- Include the Linear issue identifier in the branch name, pull request, implementation notes, or handoff when one is available.
- Before acting on an existing issue, read its current description, status, assignee, and dependencies in Linear; do not rely on stale local assumptions.

## Recommended issue hygiene

- Give each implementation task one clear owner and one current status.
- Record blockers and dependencies in the issue instead of using `Done` for unfinished work.
- Keep the issue description linked to the relevant pull request so implementation and delivery history stay discoverable.
