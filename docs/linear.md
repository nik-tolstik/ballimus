## Guidance for contributors and coding agents

- Use this project as the canonical place for planning and tracking Football Bot work.
- When a task is explicitly requested for Linear, create or update the related issue in this project and keep its status accurate.
- Do not create, edit, assign, or close Linear issues merely because code changes were made. Those external changes require an explicit request from the project owner.
- Include the Linear issue identifier in implementation notes, pull requests, or handoffs when one is available.
- Before acting on an existing issue, read its current description, status, assignee, and dependencies in Linear; do not rely on stale local assumptions.
